# Raspberry Pi 4 Model B Guide

## Overview

The Raspberry Pi 4B offers improved performance over the 3B+ with true Gigabit Ethernet and USB 3.0 support, making it ideal for higher-throughput router deployments.

## Specifications

| Feature | Specification |
|---------|---------------|
| CPU | Broadcom BCM2711, Quad-core Cortex-A72 @ 1.8GHz |
| Architecture | ARMv8 (64-bit capable, runs 32-bit by default) |
| RAM | 2GB, 4GB, or 8GB LPDDR4 |
| Ethernet | True Gigabit Ethernet |
| WiFi | 2.4GHz and 5GHz 802.11ac |
| Bluetooth | Bluetooth 5.0, BLE |
| USB | 2x USB 3.0, 2x USB 2.0 |
| GPIO | 40-pin header |
| Power | 5V/3A via USB-C |

## Building for Pi 4B

```bash
export DOCKER_BUILDKIT=1 && \
  PIMELEON_RPI_MODEL=4B \
  docker compose run --rm builder
```

## Network Configuration

The Pi 4B provides true Gigabit Ethernet and USB 3.0 ports for additional network adapters, enabling high-performance dual-port router configurations.

## Advantages Over Pi 3B+

- **True Gigabit**: Full 940+ Mbps throughput vs ~300 Mbps on 3B+
- **USB 3.0**: High-speed USB adapters for additional NICs
- **More RAM**: Up to 8GB for demanding workloads
- **Faster CPU**: Cortex-A72 vs Cortex-A53

## Known Limitations

- Higher power consumption than Pi 3B+
- Requires active cooling for sustained high loads
- USB-C power connector (ensure quality cable/PSU)
