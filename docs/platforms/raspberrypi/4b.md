# Raspberry Pi 4 Model B

The Raspberry Pi 4B offers significantly improved hardware over the 3B+, with true Gigabit Ethernet and USB 3.0. However, build support is currently partial.

## Status

🚧 **Partial Support** - Builds run but are not optimized for Pi 4B hardware

### What Works

- Build completes successfully with `PIMELEON_RPI_MODEL=4B`
- Separate cache key (`pimeleon-rpi4-...`)
- Basic boot and operation

### What's Not Yet Implemented

- **Device tree**: Currently copies Pi 3B+ DTB (`bcm2710-rpi-3-b-plus.dtb`)
  - Pi 4B needs: `bcm2711-rpi-4-b.dtb`
- **Architecture**: Hardcoded to 32-bit (armhf)
  - Pi 4B supports 64-bit (arm64) for better performance
- **CPU frequency**: Conservative 1200 MHz setting
  - Pi 4B can run at 1800 MHz
- **Boot config**: Uses Pi 3B+ optimized settings

## Hardware Specifications

| Feature | Specification |
|---------|---------------|
| SoC | Broadcom BCM2711 |
| CPU | Quad-core Cortex-A72 @ 1.8 GHz |
| Architecture | ARMv8 (64-bit capable) |
| RAM | 2 GB, 4 GB, or 8 GB LPDDR4 |
| Ethernet | True Gigabit (dedicated controller) |
| WiFi | 802.11ac dual-band (2.4/5 GHz) |
| Bluetooth | 5.0, BLE |
| USB | 2x USB 3.0, 2x USB 2.0 |
| GPIO | 40-pin header |
| Power | 5V/3A via USB-C |

## Building

```bash
export DOCKER_BUILDKIT=1 && \
  PIMELEON_RPI_MODEL=4B \
  docker compose run --rm builder
```

> **Note**: This produces a working image, but it runs as a 32-bit system with Pi 3B+ boot configuration.

## Current Build Configuration

### What Gets Applied (Same as Pi 3B+)

```ini
# config.txt - Currently NOT optimized for Pi 4B
enable_uart=1
dtparam=spi=on
dtparam=i2c_arm=on
gpu_mem=16
max_usb_current=1
arm_freq=1200      # Pi 4B could use 1800
over_voltage=2
```

### Device Tree Issue

The build currently copies:
```
bcm2710-rpi-3-b-plus.dtb  # Pi 3B+ device tree
```

Pi 4B requires:
```
bcm2711-rpi-4-b.dtb       # Pi 4B device tree
```

## Caching

Base system cache: `cache/pimeleon-rpi4-bullseye-base-v1.tar.gz`

Cache is correctly differentiated from Pi 3B+.

## Roadmap for Full Support

To fully support Pi 4B, the following changes are needed:

1. **Device tree selection** based on `PIMELEON_RPI_MODEL`
2. **Architecture option** for arm64 builds
3. **Optimized config.txt** with Pi 4B-specific settings:
   ```ini
   arm_freq=1800
   over_voltage=4
   gpu_mem=256  # More RAM available
   ```
4. **Kernel package** selection for 64-bit

See [Migration Roadmap](../../architecture/migration-roadmap.md) for implementation timeline.

## Using Pi 4B Today

The current build **will work** on Pi 4B with these caveats:

- Runs as 32-bit system (wastes 64-bit capability)
- May have boot issues if device tree mismatch causes problems
- CPU runs at lower frequency than capable
- Full RAM may not be utilized on 4GB/8GB models

**Workaround**: After flashing, manually update `/boot/config.txt` and copy the correct device tree.

## Recommended Use Cases (Once Fully Supported)
